TRIMESH & SHAPELY

Usage-first guide. Goal: slice a solid on an x/y/z grid, then get each element’s volume and centre.

1 · Create bodies

Everything is a Trimesh (vertices + faces). Primitives live in trimesh.creation.

import numpy as np, trimesh

box  = trimesh.creation.box(extents=[4, 2, 1])
cyl  = trimesh.creation.cylinder(radius=0.5, height=3)
ball = trimesh.creation.icosphere(subdivisions=3, radius=1)
ring = trimesh.creation.annulus(r_min=1, r_max=2, height=3)

# move / rotate
cyl.apply_translation([1, 0, 0])
R = trimesh.transformations.rotation_matrix(np.pi/2, [0, 1, 0])
cyl.apply_transform(R)

# booleans (need: pip install manifold3d)
plate = box.difference(cyl)      # also .union() / .intersection()

# view or export
trimesh.Scene([plate]).show()    # needs pyglet or a notebook
plate.export("plate.stl")
m = trimesh.load("plate.stl")    # load back
Slicing with cap=True and reliable volumes need a watertight mesh. Always check mesh.is_watertight after booleans or loading STL.

mesh.volumeEnclosed volume (valid if watertight)
mesh.center_massTrue centroid of the solid, uniform density. Use this for element centres.
mesh.centroidArea-weighted surface centroid. Not the solid’s centre.
mesh.bounds[[xmin,ymin,zmin],[xmax,ymax,zmax]]
mesh.is_watertightClosed surface? Required for volume/capping
mesh.areaSurface area
mesh.split()List of disconnected bodies
mesh.contains(pts)Boolean per point: inside?
m = trimesh.creation.annulus(r_min=1, r_max=2, height=3)
print(m.is_watertight, m.volume)   # True, pi*(4-1)*3 = 28.27
print(m.center_mass)               # ~[0, 0, 0]
print(m.bounds)

m.contains([[1.5, 0, 0], [0, 0, 0]])   # [True, False] (hole in the middle)

3 · Slice with planes

Two different tools. Pick by what you need back.

slice_plane: cuts the solid, keeps the side the normal points to. cap=True closes the cut so the piece is a solid again.
origin = [0, 0, 1.0]
normal = [0, 0, 1]
upper = m.slice_plane(origin, normal,  cap=True)   # z >= 1
lower = m.slice_plane(origin, -np.array(normal), cap=True)  # z <= 1
print(upper.volume + lower.volume, m.volume)       # equal
section / section_multiplane: returns the outline where a plane meets the mesh (a Path), not a solid.
path = m.section(plane_origin=[0,0,0], plane_normal=[0,0,1])  # Path3D

# many parallel sections at once (heights along the normal)
paths = m.section_multiplane(
    plane_origin=m.bounds[0], plane_normal=[0,0,1],
    heights=np.arange(0.25, 3.0, 0.5))      # list of Path2D (None if no hit)
Which to use? Solids and volumes: slice_plane. Cross-section area, outlines, 2D analysis: section + shapely.

4 · Shapely: 2D cross-sections

A section becomes a flat Path2D; its polygons_full are shapely Polygon objects (holes included).

path3d = m.section([0,0,0], [0,0,1])
path2d, to_3D = path3d.to_2D()       # older versions: to_planar()

for poly in path2d.polygons_full:    # shapely Polygons
    print(poly.area)                 # pi*(4-1) = 9.42
    print(poly.centroid)             # section centroid (2D)
    print(poly.bounds, len(poly.interiors))

# back to 3D: apply the transform to the 2D point
c = poly.centroid
pt3d = trimesh.transform_points([[c.x, c.y, 0]], to_3D)[0]

# shapely extras
poly.buffer(0.1)                     # offset
poly.intersection(other_poly)        # 2D booleans
poly.contains(shapely.geometry.Point(1.5, 0))
Use case: slice a wing or fuselage at stations along x, read poly.area, centroid and poly.bounds at each station to get an envelope.

5 · Full recipe: your objective

Slab by slab along each axis, split() after each pass so disconnected bodies inside one cell become separate elements.

import numpy as np, trimesh

def _cut(mesh, n, a, b):
    s = mesh.slice_plane(n * a, n, cap=True)          # keep >= a
    if s is None or len(s.faces) == 0: return None
    s = s.slice_plane(n * b, -n, cap=True)            # keep <= b
    return None if s is None or len(s.faces) == 0 else s

def slice_grid(mesh, step):
    lo, hi = mesh.bounds
    pieces = [mesh]
    for ax in range(3):
        n = np.eye(3)[ax]
        edges = np.arange(lo[ax], hi[ax] + step[ax], step[ax])
        out = []
        for p in pieces:
            for a, b in zip(edges[:-1], edges[1:]):
                s = _cut(p, n, a, b)
                if s is not None:
                    out.extend(s.split(only_watertight=False))
        pieces = out
    return pieces

body = trimesh.creation.annulus(r_min=1, r_max=2, height=3)
els = slice_grid(body, step=(0.5, 0.5, 0.5))

vols = np.array([e.volume for e in els])
ctrs = np.array([e.center_mass for e in els])
print(len(els), vols.sum(), body.volume)    # sums must match

# mark centres
dots = [trimesh.creation.icosphere(radius=0.04).apply_translation(c) for c in ctrs]
trimesh.Scene(els + dots).show()
Checks. Sum of volumes equals body.volume. Drop slivers with vols > 1e-9. If the sum is off, a piece was not watertight (check is_watertight before capping). For exact analytic shapes, CadQuery is an alternative.
